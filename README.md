# Portafolio de Análisis de Datos – Nair Cecilia Cabral
¡Hola! Bienvenidos a mi portfolio personal donde comparto mis primeros proyectos y aprendizajes en análisis de datos.

Soy estudiante y estoy aprendiendo en el área de ciencia de datos, con formación en ingeniería industrial. Aquí encontrarás trabajos realizados con herramientas como Power BI, SQL y Python, Excel, RStudio donde práctico desde la limpieza y manipulación de datos hasta la creación de visualizaciones y consultas.

Este repositorio está organizado en carpetas por herramienta, y en cada uno trato de explicar el proceso que seguí para resolver problemas reales o ejercicios prácticos. 

Luego, hay una carpeta de proyectos completos que utilizo múltiples herramientas para obtener un resultado final. 

Estoy en constante aprendizaje y este espacio es para mostrar mi progreso y ganas de seguir creciendo en esta área.

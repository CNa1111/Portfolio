## Excel y Análisis de Datos

Este repositorio reúne ejercicios, prácticas y proyectos desarrollados durante mi formación en Excel Avanzado aplicado al análisis de datos, incorporando herramientas como Power Query y Power Pivot.

### Excel Avanzado
* Funciones avanzadas
* Tablas dinámicas
* Segmentación de datos
* Validación y limpieza de información
* Formato condicional
* Gráficos dinámicos
* Manejo de grandes volúmenes de datos

### Power Query
* Importación de datos
* Limpieza de datos
* Organización y preparación de información
* Combinación de tablas

### Power Pivot
* Modelado de datos
* Relaciones entre tablas
* Medidas y cálculos utilizando DAX
* Creación de métricas para análisis

### Objetivo del repositorio
Aplicar herramientas de análisis de datos en Excel para: 
Organizar información de manera eficiente, analizar datos mediante reportes dinámicos, y mejorar la visualización y comprensión de datos.

### Herramientas utilizadas
* Microsoft Excel
* Power Query
* Power Pivot
* DAX
* Tablas y gráficos dinámicos

### Contenido del repositorio
En este repositorio se incluyen:

* ejercicios prácticos,
* dashboards,
* análisis de datos,
* y archivos desarrollados durante el curso.

### Enfoque

El enfoque del curso estuvo orientado al análisis y manejo de datos utilizando herramientas avanzadas de Excel aplicadas a contextos administrativos y empresariales.
